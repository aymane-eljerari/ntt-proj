# NTT Benchmarking Suite
This repository contains CPU, GPU (Radix-2 and Radix-4), and OpenFHE implementations of the Number Theoretic Transform (NTT). The included scripts automate the benchmarking, hardware profiling, and data aggregation required to reproduce the performance report.

> [!NOTE]
> This README, along with the bash and Python scripts in this repository, were generated by Claude.

### Environment Setup
Launch the provided Docker container to ensure all dependencies (CUDA, OpenFHE, OpenMP) are configured correctly. Compile the project inside the container.

### Start the docker environment
```
./dkr-run.sh
```

### Compile the source code and run
```
mkdir build && cd build
cmake .. && make && ./bench_ntt
```
### Execute Performance Sweeps
Run the automated benchmarking scripts to generate the end-to-end runtime data across different polynomial degrees and OpenMP thread counts.

### Run runtime vs. polynomial degree sweeps (N=10 to 20)
```
./run_sweep.sh
```

### Run OpenFHE and Custom CPU strong/weak scaling sweeps
```
./cpu_weak_strong_scaling_sweep.sh
```

### GPU Hardware Profiling
Profile the Radix-2 and Radix-4 GPU kernels using NVIDIA Nsight Compute to capture performance metrics.
```
./run_ncu.sh
```

### Aggregate the raw NCU output into summary tables
```
python3 ncu_aggregate.py
```
